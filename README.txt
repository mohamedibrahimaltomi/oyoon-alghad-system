
1) افتح Supabase > SQL Editor ونفّذ الملف schema.sql كاملًا.
2) بعد التنفيذ، ارفع الملفات على استضافة ثابتة أو افتح index.html.
3) اسم المستخدم الافتراضي:
   admin
   كلمة المرور:
   admin123

ملاحظات مهمة:
- هذه الحزمة تستخدم نظام مستخدمين مخصص باسم مستخدم + كلمة مرور.
- يتم إنشاء سجل عمليات ونسخة احتياطية بعد كل عملية مهمة.
- استيراد البصمة يدعم Excel وCSV.
- إذا أردت تشديد الأمان أكثر لاحقًا، استبدل سياسات RLS المفتوحة بسياسات مخصصة لكل دور.
